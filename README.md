### ✨ Key Features - HR Modules

**Employee Management 👨‍💼**
- Add, Update, Delete & View Employee Details (CRUD)
- Search Employee by ID, Name, Department
- Employee Profile with Photo & Documents

**HR & Admin Panel 👮**
- Department-wise Employee Management
- Attendance & Leave Management Module
- Secure Admin Login with Spring Security
- Dashboard with Total Employees, Departments Analytics

**Additional Features**
- Validation & Error Handling
- Responsive UI for HR Team
